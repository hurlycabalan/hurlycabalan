## Featured project

### [Soc-Investigation](https://github.com/hurlycabalan/Soc-Investigation)

A SOC investigation portfolio with 11 completed scenarios (SC-01 to SC-06 and TL-01 to TL-05). Each one follows the same template:

- Alert summary and severity
- Investigation in Microsoft Sentinel and Defender XDR using KQL
- True positive or false positive decision, with the false-positive branch
- MITRE ATT&CK mapping
- Mitigation
- Lessons learned and interview Q&A

The scenarios use pre-recorded log data from the Microsoft Sentinel Training Lab (multi-vendor, up to an 8-vendor capstone). They are investigation practice, not live attacks.
